# Iterations

Each loop records the expectation before checking, what broke, and the fix. A result counts only after a check that could have failed has passed.

## Loop 1 — dollar-diff test harness (2026-10-21)
- **Expected:** replaying each task's gold actions as an "agent" trajectory gives zero dollar loss, and injected mistakes give the injected loss.
- **What broke:**
  1. The first real-task tests used airline tasks 0–4. **None of them contains a money-moving action** (task 0 has no actions at all), so "zero loss" passed whatever the code did. The tests were vacuous.
  2. The hand-built replay had blank tool outputs. tau2's strict replay rejects those, so the replay never ran on tasks that change state.
- **Fix:**
  - Tool outputs are now generated by executing the actions in a scratch environment.
  - Tests use the first tasks whose gold actions move money.
  - A guard asserts that the replay changed the DB.
  - A suite-level check requires at least 7 of the first 10 money tasks to change a money position.
  - Two deliberately wrong real-task cases were added: an extra $100 certificate (must give exactly $100 first-party loss) and an unwarranted cancellation (must give a positive loss).
- **Also found:** task 12's gold action adds *free* bags, so it moves no money. The first guard ("money must move") wrongly failed on it and was relaxed to "the DB must change".
- **Result:** 15/15 tests pass.
- **Still open:** the dollar model values money only. Wrong flights or seats with no price change score $0 even when the DB doesn't match. Report these separately as non-monetary failures.
